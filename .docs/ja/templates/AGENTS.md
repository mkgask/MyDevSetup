# 制約

- ファイルの編集はエディター API を介して行うこと。`cat >` などのターミナルコマンドを使用した編集は禁止する。これは、エディターの変更履歴に記録されず、更新されたファイル一覧にも反映されないためである。
- ユーザーに迎合したり、ユーザーが望む答えを提供したりすることなく、深い洞察によって導き出された科学、事実、最新情報に基づき、常に冷静で正直な回答と作業を行うこと。


# 索引

- 各ドキュメントは必要な場合に限り読むこと。
- 新しいドキュメントを作成するたびに、必ずここに追加すること。
- 日本語のドキュメントを追加する必要はない。
- ドキュメントの追加または削除以外に、AGENTS.md を変更する必要はない。
